# DESCRIPTION:
 First, the socket was fixed as the base component. Then, the spigot was inserted and aligned with the socket using coincidence constraints to ensure both are on the same axis. After that, the cotter was positioned through the aligned slots using appropriate constraints so that it fits properly.The main aim of this assembly is to show how the cotter locks both parts together and allows transmission of axial force without relative movement. This process helped in understanding constraint application and real-time assembly of mechanical joints.
 

# CHALLENGES FACED TO DEVELOP:
 While assembling the cotter joint in CATIA, aligning the spigot and socket properly was difficult at first. Small errors in axis alignment caused mismatch in slots. Positioning the cotter accurately was also challenging since it required perfect fit. Sometimes, applying too many constraints led to over-constraining errors. There were also issues with parts overlapping due to improper constraints. Fixing the base component was necessary to avoid unwanted movement. Understanding which constraint to use at each step took some practice. Overall, maintaining dimensional accuracy and proper constraint application was the main challenge.
